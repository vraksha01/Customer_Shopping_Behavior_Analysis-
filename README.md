# Customer_Shopping_Behavior_Analysis-
Data analytics project showcasing customer behaviour analysis using python, SQL &amp; Power BI

## Project Overview
This project analyzes customer shopping behavior to identify purchasing patterns, product preferences, and discount usage. It follows an end-to-end data analytics workflow using Python, PostgreSQL, and Power BI to transform raw data into meaningful business insights.

**Objective:** To analyze customer shopping data and support data-driven business decisions.

## Dataset
The dataset contains customer demographics, purchase amounts, product categories, discounts, payment methods, shipping preferences, previous purchases, and customer ratings.

## Tools & Technologies
- **Python:** Data loading, cleaning, and exploratory data analysis (EDA)
- **Pandas & NumPy:** Data manipulation and preprocessing
- **Jupyter Notebook:** Python analysis
- **PostgreSQL:** SQL queries and business analysis
- **Power BI:** Interactive dashboard and data visualization
- **Gamma:** Project presentation
- **GitHub:** Project documentation and version control

## Project Steps

### 1. Data Loading & EDA — Python
- Loaded the dataset into a Pandas DataFrame.
- Examined data structure, column types, and summary statistics.
- Identified missing values and explored data patterns.

### 2. Data Cleaning — Python
- Handled missing values.
- Standardized column names and data formats where required.
- Prepared the dataset for further analysis.

### 3. Data Analysis — PostgreSQL
Used SQL queries to answer business questions, including:
- What is the total purchase amount by gender?
- Which products have the highest average customer ratings?
- How are discounts used by customers?
- What are the top three products within each category?
- How can customers be segmented based on previous purchases?
- What percentage of purchases involve discounts?

SQL concepts used: filtering, aggregate functions, `GROUP BY`, `CASE` statements, CTEs, and window functions.

### 4. Dashboard Development — Power BI
Created an interactive dashboard to explore:
- Customer and purchase metrics
- Product and category performance
- Customer ratings and shopping preferences
- Discount usage and customer segments

### 5. Reporting & Presentation — Gamma
Prepared a project report and presentation to communicate the analysis, key findings, and business recommendations.

## How to Run
1. Clone or download this repository.
2. Open the Jupyter Notebook and update the dataset path.
3. Install the required Python libraries, including Pandas and NumPy.
4. Run the notebook cells to perform data exploration and cleaning.
5. Create a PostgreSQL database and load the prepared dataset.
6. Execute the SQL queries from the `sql` folder.
7. Open the Power BI dashboard using Power BI Desktop.
8. Review the project report and presentation.

This project demonstrates an end-to-end data analytics workflow, from data preparation and SQL analysis to dashboard development and business reporting. It showcases practical skills in Python, PostgreSQL, Power BI, data visualization, and analytical problem-solving.
